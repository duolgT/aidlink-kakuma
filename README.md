
# AidLink Kakuma

### Connecting Communities to Essential Services

AidLink Kakuma is an offline-first Progressive Web App
(PWA) prototype designed to make essential community
information more accessible to refugees and host
communities in Kakuma, Kenya.

Developed for the RefuTech Academy Hackathon 2026.

## The Problem

Accessing reliable information about healthcare,
education, emergency guidance, and community services
can be challenging, especially where internet
connectivity is limited.

## Our Solution

AidLink Kakuma brings community service information
and practical digital tools together in one platform.

### Core Features

**1. Service Finder**
- Search and filter community service listings
- Browse services by category
- Explore an interactive map
- View individual service details

**2. Emergency Guide**
- Browse safety and emergency topics
- Search emergency guidance
- Read step-by-step informational guides
- Bookmark important guides

**3. Community Reporting**
- Create reports about general service challenges
- Save drafts in the browser using IndexedDB
- View previously saved reports
- Delete saved drafts

**4. Progressive Web App**
- Install on supported devices
- Cache app pages for offline access
- Display offline connection status
- Preserve locally saved data where browser storage allows

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd aidlink-kakuma
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Status

Hackathon prototype.

Current limitations:
- Service listings are demonstration data.
- Emergency guidance requires local verification.
- Community reports are saved locally and are not
  transmitted to organizations.
- Online map tiles require internet connectivity.
- Browser storage can be cleared or evicted.

This application is not an official emergency
response or aid reporting channel.
